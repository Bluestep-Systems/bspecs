Second issue of the tooling digest. Since August 27 the bluestep-tools plugin went from 0.30.0 to 0.37.1, and a batch of gateway MCP fixes went live. The big theme: your agent carries less context and spends fewer tokens. (No new b6p CLI this time — v0.7.0 is still current.)

Copy everything in the grey box and paste it into a new Claude Code, Cursor or Codex session, opened in one of your BlueStep projects.
Less context, fewer tokens
• A rules file a third the size. Your project's AGENTS.md is re-read on every turn. It's ~40 lines now instead of 142; the rest is served only when a task needs it.
• Compaction at 400K. Models make more mistakes as the context gets very large, and every request re-reads the whole history. In Claude Code, /b6p-setup turns on compaction at 400K — the value the BlueStep team suggests — and tells you first. Already set your own autoCompactWindow? It keeps yours. (No effect on 200K models.)
• Less loaded into every session. Fewer skills, so the skill descriptions every session starts with went from 5.0 KB to 3.5 KB.
• Lighter models for simple tasks. /spec-execute picks a lighter model for tasks marked mechanical or routine, and steps up once if it needs to.
Existing projects: run /b6p-setup once in each one — the prompt above does it. It swaps in the short rules file, keeping every line that's yours, and adds the compaction setting. /b6p-setup --all checks every BlueStep project on your machine.
Also in the plugin
• Know what a push overwrites. /b6p-push passes --yes, which silently overwrites platform-side edits and deletes platform-only files. The skill now warns you and points to /b6p-audit when the platform may have changed.
• Setup runs itself. /b6p-setup handles the machine and the project in one go, and /b6p-pull, /b6p-push, /spec-create and /quick-task run it for you when a folder isn't ready.
• The guardrail hooks really block now. They had been silently letting everything through. If an edit under declarations/ gets blocked, that's why.
• Reference corrections. Pages that had bitten people were fixed — field-access grants, sibling files in scripts/, what compiles where — and nine new pages were added.
• A correction to our last issue. The "option lists cut display names short by one character" gotcha wasn't a platform bug, so it's gone.
To update, run /plugin marketplace update
Codex: re-trust the plugin's hooks afterwards.
BlueStep gateway MCP
• Silent failures fixed. field, batch_fields, form and option_list_item now apply what you send — names, autoCopy, singleEntry:false, export values — and check it before reporting success.
• form_permission merges by default. It used to replace a form's whole permission set; now it only adds or updates the subjects you name. Replace-everything is still there with mode: REPLACE.
• New parameters. schedule and onDemandIdentifier on create_script / update_script, primaryFormId to wire a save formula to its form, and contentId on update_pagelet.
Nothing to install — these changes are already live on the gateway.
